# HQPlayer Web Controller

A small, modern web controller for Signalyst HQPlayer (Desktop and Embedded): pick
an instance, see what it is doing, change filters, modulators, mode and rate, and
apply your own presets from any phone, tablet or browser.

**Status: pre-alpha, design stage.** See [docs/design-v1.md](docs/design-v1.md).

It speaks HQPlayer's published control protocol (XML over TCP 4321), the same one
Signalyst publishes as MIT-licensed source in the HQPlayer SDK.
